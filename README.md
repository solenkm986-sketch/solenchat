# SolenChat — Этап 1: фундамент

Этот этап включает: структуру проекта, дизайн-систему (светлая/тёмная
тема), подключение к Supabase, авторизацию (регистрация/вход/выход),
таблицу профилей с RLS-политиками и базовый адаптивный каркас интерфейса.

## Что уже готово

- Next.js 14 (App Router) + TypeScript (строгий режим) + Tailwind CSS
- Тема оформления: светлая / тёмная / системная, без "вспышки" при загрузке
- Supabase: клиенты для браузера, сервера и middleware (`@supabase/ssr`)
- Регистрация и вход через Server Actions с валидацией `zod`
- SQL-миграция `supabase/migrations/0001_init.sql`:
  - таблица `profiles` с ограничением формата `username`
  - RLS-политики (просмотр — всем авторизованным членам семьи,
    редактирование — только своего профиля)
  - триггер, который создаёт профиль автоматически при регистрации
    и делает первого зарегистрированного пользователя `owner`
- Защита приватных страниц через `middleware.ts` (редирект на `/login`)
- Базовый unit-тест валидации username (`npm run test`)

## Как запустить локально

### 1. Установите зависимости

```bash
npm install
```

### 2. Создайте проект Supabase

1. Зайдите на https://supabase.com → New Project.
2. Дождитесь создания проекта.
3. Перейдите в **Project Settings → API** и скопируйте `Project URL`
   и `anon public` ключ.

### 3. Настройте переменные окружения

```bash
cp .env.example .env.local
```

Откройте `.env.local` и вставьте значения из шага 2.

### 4. Примените миграцию базы данных

Проще всего — через SQL Editor в панели Supabase:

1. Откройте **SQL Editor** в вашем проекте Supabase.
2. Скопируйте содержимое `supabase/migrations/0001_init.sql`.
3. Вставьте и нажмите **Run**.

(Альтернатива для тех, кто работает через Supabase CLI:
`supabase link --project-ref <ваш-ref>`, затем `supabase db push`.)

### 5. Отключите подтверждение по e-mail (для локальной разработки)

Чтобы не настраивать SMTP на старте: **Authentication → Providers → Email**
→ выключите **Confirm email**. Это можно и нужно будет включить обратно
позже, при подготовке к продакшену.

### 6. Запустите проект

```bash
npm run dev
```

Откройте http://localhost:3000 — вас перенаправит на `/register`.
Создайте первый аккаунт — он автоматически получит роль `owner`.

### 7. Проверка

```bash
npm run typecheck   # проверка типов
npm run test        # unit-тесты (валидация username)
npm run lint        # ESLint
```

## Структура проекта

```
src/
  app/
    (auth)/login/page.tsx        — страница входа
    (auth)/register/page.tsx     — страница регистрации
    page.tsx                     — защищённая главная страница
    layout.tsx, globals.css      — корневой layout и тема
  components/
    ui/                          — примитивы (Button, Input)
    shared/                      — AppShell, ThemeToggle, SignOutButton
  lib/
    supabase/                    — клиенты (browser/server)
    actions/auth.ts              — server actions входа/регистрации/выхода
    validation/auth.ts           — zod-схемы
  middleware.ts                  — защита приватных страниц
  types/database.types.ts        — типы таблиц Supabase
supabase/migrations/0001_init.sql — миграция БД (профили + RLS)
tests/unit/username.test.ts      — unit-тест валидации
```
